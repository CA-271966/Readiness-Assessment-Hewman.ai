# Hewman.ai AI Integration Readiness Assessment

A 37-question diagnostic tool measuring organizational readiness to integrate AI on the human side: executive sponsorship, leadership alignment, manager readiness, culture and psychological safety, operational mapping, and governance.

Built on the AI Integration Readiness Framework by Hewman.ai.

## Tech

- React 18
- Vite
- Recharts (radar chart visualization)
- Formspree (email capture)
